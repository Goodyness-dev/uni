# ScholarPilot reality audit — 2026/10/12

The active v1 application is a real, bounded tool-using agent inside a predefined workflow. A model chooses actions from nine tools; it researches official pages, selects source evidence, generates and independently challenges text, revises, requests evidence, or skips an opportunity. Ten decisions per continuation window and per-tool limits control cost. This is not a general autonomous scholarship operator.
